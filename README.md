# J-Neon

Instaladores de la app de presupuestos de J-Neon.

La última versión está en [Releases](https://github.com/lovera2025/j-neon/releases/latest):

- **Windows:** `J-Neon-Setup-x.y.z.exe`
- **Android:** `J-Neon-x.y.z.apk`

La app avisa cuando hay una versión nueva desde Ajustes > "Buscar actualizaciones". Actualizar no borra los datos.
